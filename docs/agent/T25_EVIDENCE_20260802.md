# T25 evidence expansion — 2026-08-02

## Scope and decision boundary

This report strengthens T25 beyond the owner's 47 supplied annotations. It
joins the 43 canonical cases to runtime telemetry, checks recurrence in retained
history, verifies selected terminology and grammar against external sources,
and maps candidate fixes to the current pipeline. It does **not** authorize a
production prompt, glossary, normalization, quality-gate, STT, routing, or
deadline change.

Evidence classes used below:

- **R1 — direct runtime:** verifies that an event, output, route, or metadata
  value was recorded. It does not prove a proposed root cause.
- **R2 — retained-history recurrence:** strengthens evidence that a pattern is
  repeatable. A repeated text match still does not prove the same spoken word.
- **E1 — authoritative external:** official product/entity material or a
  national-language source verifies a term, identity, or grammar claim.
- **E2 — corroborated external:** multiple public domain sources agree, but no
  publisher-owned term page was found.
- **H — human inference:** useful hypothesis from source/output/context.
- **A — audio needed:** the retained run has no WAV, so the proposed STT
  reconstruction cannot be treated as ground truth.

The lossless annotation source remains
`data/manual_quality_annotations_20260801.json`. Corrections based on later
evidence belong in `data/semantic_quality_eval_20260801.json`; the source
annotation must not be silently rewritten.

A second, audio-retained intake from the 2026-08-02 runtime is documented
separately in `docs/agent/T25_RUNTIME_AUDIO_EVIDENCE_20260802.md`. Its 95 raw
annotations and provenance manifest do not replace or merge into this 43-case
evaluator set. Sixteen independently reviewed bounded contrasts from that
later intake now live in their own
`data/semantic_quality_eval_20260802.json`; references pass 16/16 and captured
outputs fail 16/16. Its 21 audio-required cases were also replayed separately
through both SenseVoice and faster-whisper; see
`docs/agent/T25_DUAL_ASR_REPLAY_20260802.md`. Neither dual-ASR agreement nor
those atomic contrasts authorize a production change without owning-layer
controls.

## External verification and annotation corrections

### Promoted evidence

- **qa006 — active voice:** Korean `패다` is transitive “to beat/hit”, and
  `-게 되다` describes reaching a state. `레신을 패게 돼` does not support
  “被雷神打”. **E1.**
- **qa016 — throat sense:** the National Institute of Korean Language lists
  `목이 붓다` and `목이 아프다` under the throat sense. “脖子腫” is not the
  intended reading here. **E1.**
- **qa020 — waiting screen:** SOOP's broadcasting manual uses `대기화면` for
  the pre-broadcast waiting screen. “開機畫面” is wrong. **E1.**
- **qa021 — facial tracking:** SOOP usage and VTuber documentation support
  `페이셜` as facial capture/tracking in this context. **E1/E2.**
- **qa034 — video-call fan sign:** a Weverse bilingual example directly maps
  `영통 팬싸` to “video call fan sign”. **E1.**
- **qa042 — negative-question inference:** `-을까` is interrogative/inferential;
  the following clause disambiguates the sentence toward “或許很健康／換得了
  健康”, not “不太健康”. **E1.**
- **qa043 — conditional subject/voice:** `N이면` means “if it is N”, and
  `혼냈지` is active. The output reverses both the participant and voice.
  **E1.**

### Partially promoted evidence

- **qa004:** `방을 파다` is attested as creating a chat/game room, but
  `방파샘→방 파셈` and `팔아요→파요` remain A.
- **qa010:** public Palworld sources support `소환의 제단`; the source's
  `소환의 재단` contains a source/STT normalization issue in addition to target
  mistranslation.
- **qa019:** SOOP defines `시그니처 풍선`; `시그풍` means a custom/signature
  star-balloon image, not an autograph or generic “signature illustration”. The
  near-sound repair `시거풍→시그풍` remains A.
- **qa031/qa032:** official Hearts2Hearts entity spellings are JIWOO, CARMEN,
  YUHA, STELLA, JUUN, A-NA, IAN, and YE-ON; `이연→Ian` remains A, and a
  group-name-plus-`분들` interpretation must stay sentence-scoped.
- **Palworld glossary candidates:** PlayStation's Korean and Traditional
  Chinese pages support `팰→帕魯` as E1. Public game databases consistently use
  `제트래곤`, `벨라루주`, `소환의 제단`, `벨라루주의 석판`, `빙천마`, and
  `썬도그`; these are E2 rather than publisher-verified per-term entries.

### Corrected reference

- **qa033:** the supplied reference said Yuri. Official Hearts2Hearts profiles
  contain no Yuri; YUHA and STELLA were both born in 2007. The strongest
  contextual reconstruction is therefore `유하랑`, not `유리랑`. The canonical
  reference is corrected to Yuha and marked
  `externally_supported_candidate_audio_pending`. The observed UR:L output is
  still a confirmed overcorrection, but the exact spoken syllables remain A.

Still H/A rather than promoted ground truth: qa005's unresolved names,
`공청기`, `노래책 날렸어요`, and every near-sound reconstruction for which the
two source runs retained no audio.

## Verified pipeline ownership and falsified shortcuts

The annotation's `rule_target` is triage metadata, not verified code ownership.
The 43 cases currently propose 14 `source_norm`, nine `streamer_profile`, five
`target_replacement`, and 15 `translation_prompt` changes, but the actual
mechanisms have narrower contracts:

| Candidate layer | Verified behavior | Principal blast radius | Cheapest falsification |
| --- | --- | --- | --- |
| Source normalization | Shared/profile/conditional tables apply exact `str.replace` before cache/model lookup (`modules/translation_corrections.py`, `modules/translator.py`) | A near-sound repair can rewrite an unrelated word before every downstream stage | Positive case plus unrelated-source, wrong-profile, and idempotence tests |
| Name rendering | Source-alias and profile gated, suffix aware; an alias preceded by another Hangul syllable is rejected | Relaxing the boundary can match names inside ordinary words | `임마냥이`, spaced `이 마냥이`, plain `마냥이`, and unrelated containing-token controls |
| Target correction | Source terms only gate replacement of enumerated **wrong target strings** | It cannot guarantee a canonical source term will be generated, and substring repair can damage grammar | Known wrong output, unrelated-source, wrong-profile, and already-correct output |
| Streamer STT terms | `streamer_profiles.json` supplies persistent per-streamer hot terms | Episode/game vocabulary can pollute every stream for that profile | Glossary membership plus unrelated-speech audio replay |
| Manual activity STT terms | `cfg.translation.current_activity` feeds `scene_stt_terms.json` into the Groq prompt | Only works when activity is explicitly set | `terms_for_activity("Palworld")` positive/empty/unrelated tests, then retained-audio A/B |
| Automatic activity | Published as a translation-only capsule and explicitly does not activate STT hot terms | Treating it as STT control would violate the current safety contract | Existing scene-context contract tests |
| Translation prompt/profile | Standard and Qwen profile text are separately appended to the selected prompt | Prompt growth can regress unrelated semantics and raise token cost | Prompt snapshot/parity first; identical-settings paid A/B only after approval |
| Runtime quality | Reference-free shape, script, repetition, bracket, and narrow amount telemetry | Cannot judge active/passive voice, entities, reference, or ordinary lexical sense | Known-bad captured outputs must trigger the proposed new assertion while matched OK controls remain clear |

Two proposed shortcuts are already contradicted by code/config evidence:

- **qa008:** both prompt families already state exact number preservation and
  define Korean `만=10,000`. Adding the same instruction again is not a
  demonstrated fix. The current amount detector accepts only narrow shapes, so
  this case remains invisible to selective retry.
- **qa033:** both URL profile prompts already limit UR:L to explicit group
  aliases/context, and deterministic source normalization does not map `유아`
  to UR:L. Repeating the guard is unlikely to establish causality; this is a
  model-adherence experiment plus an audio-pending source reconstruction.

Case 022 is also narrower than its label suggests: `마냥` already exists in
the URL STT glossary, translation profile, corrections, and name rendering.
The observed `임마냥이` misses the current preceding-Hangul alias boundary;
`깻잎이` is a separate unverified entity decision.

This owner map supports six separate candidate cards rather than one bundled
fix: assertion/control gate; deterministic known-output rescue; URL stable
entities; Palworld manual-activity STT experiment; prompt experiments split
between local semantics and discourse/history; and future retained-audio STT
evidence collection.

## Evidence-backed next gates

1. Extend the initial eight deterministic semantic assertions only when an
   E1/E2 fact has a stable expected term or forbidden rendering; do not encode
   A reconstructions as hard assertions.
2. Human-review a matched OK control slice from the same two runs, stratified by
   profile and forced/non-forced cut. The current 391-event pool is only the
   sampling frame.
3. Establish the current production-model baseline with identical
   profile/context settings. Keep activity glossary, bounded source
   normalization, target rendering, prompt, and quality telemetry as separate
   candidates so attribution remains possible.
4. Require no high-severity regression on reviewed controls. Use deterministic
   replay for blast-radius hygiene, not as proof of model improvement.
5. Paid A/B model calls still require an explicit owner decision.
