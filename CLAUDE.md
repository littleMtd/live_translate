# CLAUDE.md

This file is the Claude Code entry point. Repository-wide process and safety
rules have one canonical home: `AGENTS.md`.

## Default Read Order

1. `AGENTS.md`
2. `docs/agent/AGENT_BRIEF.md`
3. `docs/agent/TASK_INDEX.md`
4. `docs/agent/VALIDATION_BRIEF.md` before application/config/data behavior
   changes or when choosing validation

Do not read large reference documents in full by default. Search for the relevant section first.

Use `TASK_INDEX.md` to route backend, database, frontend, runtime, translation,
STT, tooling, optimization, architecture, and archive tasks. Do not duplicate
the routing or roadmap tiers here. Follow the cross-review workflow in
`AGENTS.md` for implementation work.
