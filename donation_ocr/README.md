# 斗內翻譯面板(原型)

看直播時開著:把**綠色空心框**拖到斗內/聊天區 → 框內新出現的韓文被 OCR → 用既有 translator 翻成 zh-TW → 顯示在置頂小面板。目的:主播對斗內有反應但沒念出來時,你能看懂他在反應什麼。

## 跑法(repo 根目錄)

```
live-subtitle-env\Scripts\python.exe donation_ocr\app.py          # 單獨跑
live-subtitle-env\Scripts\python.exe main.py --donation-ocr      # 跟主管線一起啟動
```

第一次建議先 dry-run(只 OCR 不翻譯、不打 API),確認框的位置和 OCR 有在動:

```
live-subtitle-env\Scripts\python.exe donation_ocr\app.py --dry-run
```

跟主管線一起跑**不會撞 DB**:面板行程跑在 DB-less 模式(不讀寫 SQLite、不寫歷史檔,in-memory cache 照常),與主管線的翻譯 DB 寫入零競爭。斗內文字幾乎一次性,DB cache 本來就沒價值;每則紀錄都在 session_*.jsonl。

## 用法:兩個視窗

- **綠色空心框** = OCR 區域,無邊框、只有一圈綠邊。**抓綠邊拖動、抓右下角小方塊縮放**,即時生效;框內是透明的、可以直接點到底下的直播。每場版面不同就直接拖,不用改參數。位置會記住,下次啟動自動還原。
- **就地譯文(取代式)**:新斗內一出現,**原文立刻**畫在該行位置(黑底綠邊標籤),譯文好了原地換字;**下一則斗內出現時整批取代**,不堆疊、不捲動——符合「斗內同一時間只有一則」的彈窗型顯示。沒有新斗內時,標籤在譯文換上後 `--overlay-ttl` 秒(預設 8)自動消失。`--no-overlay` 可關。dry-run 只畫原文。
- **黑色面板** = 翻譯歷史,最近 N 則,新的在上。把它放在框外(放進框裡會被自己 OCR 到)。

**關翻譯面板即結束**(綠框沒有關閉鈕)。每場的「原文+譯文」存 `scratch/donation_panel/session_*.jsonl`,事後可回看。

## 常用參數

| 參數 | 預設 | 說明 |
|---|---|---|
| `--profile` | `isegye_lilpa` | 看誰就設誰;`--profile ""` 沿用 config 現值 |
| `--interval` | 2.5 | 擷取間隔秒 |
| `--dry-run` | off | 只 OCR 不翻譯 |
| `--max-rows` | 8 | 面板保留最近 N 則 |
| `--all-screens` | off | 直播在副螢幕時加這個 |
| `--roi` | 0,680,640,380 | 框的初始位置(僅第一次,之後記住上次) |

## 已知限制(原型刻意不解)

- 純英數的留言會被濾掉(要求至少含一個韓文字)。
- 就地標籤不追蹤捲動(取代式+過期自清;彈窗型斗內剛好,捲動清單會短暫錯位)。
- 斗內跳得比翻譯快時,被取代那則的譯文只在面板歷史/log 裡。
- 洗版太快時(수금타임)可能漏抓——本來就不是為那種場設計的。
